# Frontend Labs

Репозиторій з лабораторних робіт з курсу «Frontend-розробка».

**Автор:** Даскалюк

## Структура репозиторію

| Папка | Опис |
|-------|------|
| `laba1/` | React-проєкт «Світлофор» (Vite), який розвивається від ЛР1 до наступних лабораторних |

## Лабораторні роботи

Кожна лабораторна виконується в окремій гілці:

| Гілка | Тема | Статус |
|-------|------|--------|
| `laba1` | Git, GitHub, базовий React-проєкт на Vite, компоненти `Light` і `TrafficLights` | виконано |
| `laba2` | Стан, події та похідний інтерфейс: інтерактивний світлофор | виконано |
| `laba3` | Поведінка в часі, ефекти та анімація: автоматичний світлофор | виконано |

## Технології

- React (хуки `useState`, `useEffect`)
- Vite
- JavaScript (JSX)
- CSS transitions
- Git / GitHub

## Як запустити проєкт

```bash
git clone <посилання-на-репозиторій>
cd frontend-labs
git checkout laba3
cd laba1
npm install
npm run dev
```

Після запуску відкрийте адресу, яку покаже Vite (зазвичай `http://localhost:5173`).
